# Memory Foundation v1 Freeze Report

## Decision

Foundation v1 is frozen after deterministic and live validation. The live run
had no execution or semantic hard failures; the only non-pass result is the
accepted MEM-014 atomization warning.

## MEM-008 Root Cause

Flash could return a registered preference predicate whose object belonged to a
different semantic domain, for example `preference.food.cuisine` with object
`看展`. The schema and registry accepted the predicate, so the error reached
admission and relation governance. The fix adds bounded canonical-domain
consistency validation at normalization/repair time. A uniquely supported
registered sibling is selected; otherwise the claim falls back to Custom. No
ontology enum or Store field was added.

## Freeze Boundary

After this freeze, changes to canonical state identity, admission policy,
deterministic relation rules, lifecycle core, relationship evidence precedence,
context projection, and contact semantic-family lifecycle require a new issue
and regression baseline. Long-tail Judge prompts/thresholds, Retriever
weighting, Validator thresholds, lifecycle commit, ontology expansion, and
multi-target mutation remain out of scope.
